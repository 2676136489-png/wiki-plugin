# iGEM Glass Wiki 插件

面向 iGEM 竞赛团队的多页面 Wiki 模板，静态优先架构。19 个页面共用一套设计系统，9 个交互插件各配独立演示页；无构建步骤，可直接在浏览器中打开。

## 1. 项目背景

iGEM 对交付环境有明确约束：最终内容、图片、脚本与样式必须全部纳入指定 GitLab 仓库，评审在该环境中访问页面。任何依赖 Node 构建、CDN 资源或外部服务的方案都会在交付阶段失效。

团队通常缺少前端工程资源，模板需要在无构建、离线可用的前提下提供完整的竞赛页面结构与视觉体系。

## 2. 目标用户与场景

| 角色 | 核心场景 |
| --- | --- |
| iGEM 团队成员 | 按评审要求组织项目内容，替换为真实材料后提交 |
| 队伍负责人 | 核对页面覆盖的评审条目，分配撰写任务 |
| 后续接任成员 | 在无本地环境的情况下修改 HTML 并提交 |

## 3. 问题定义

| 问题 | 现状 | 目标 |
| --- | --- | --- |
| 交付环境受限 | 构建产物与 CDN 资源无法使用 | 静态优先，全部素材随仓库交付 |
| 页面缺少组织 | 内容按成员习惯堆放 | 按评审阅读顺序组织，每页对应评审条目 |
| 视觉不统一 | 多人协作导致风格割裂 | 一套设计系统约束全部页面 |
| 交接成本高 | 依赖本地环境与构建流程 | 无需配置，修改 HTML 即可提交 |

## 4. 功能范围

| 类型 | 数量 | 页面 |
| --- | ---: | --- |
| 项目页 | 10 | 首页、描述、工程、结果、模型、安全、实践、归属、贡献、协作方式 |
| 插件演示 | 9 | 全部插件、命令面板、前后对比滑杆、证据筛选卡、悬浮工具坞、术语悬浮注释、磁吸卡片、粒子场背景、滚动叙事 |

项目页按评审阅读顺序组织：项目描述、设计、建模、工程与结果，随后为安全、人类实践、贡献与归属。每页对应评审表格中的一项，团队无需自行判断内容归属。

## 5. 设计系统

- 配色：近黑深青、冷白纸面、信号青绿。
- 字体：Noto Sans SC 用于中文，Instrument Serif 用于拉丁标题，Inter 用于插件演示页。
- 组件：滚动进度条、章节索引、证据筛选、批次图表、标签页与手风琴。
- 样式分层：`dossier.css` 承载项目页设计系统，`style.css` 承载插件演示页样式，两者均不含业务逻辑。

## 6. 技术实现

iGEM 交付约束对应的实现方式：

- 无构建步骤，修改 HTML 后可直接提交。
- 无 CDN 与外部请求，字体、插图与脚本全部位于仓库内。
- PHP include 为可选项，未启用时页面功能不受影响。
- 占位内容与待替换素材均标注来源，便于团队交接。

## 7. 质量验证

- 19 个页面均在离线状态下打开验证，无外部请求。
- 字体通过本地 `assets/fonts/` 加载，路径在独立部署与子目录部署下均有效。
- 导航、目录高亮、标签页、证据筛选与对比滑杆逐项验证。
- 页面已在最新版 Chrome、Edge、Firefox 与 Safari 验证。

## 8. 范围边界

- 页面内容为示例项目（LUMEN 低氧表达项目），交付前需替换为团队真实材料。
- 模板不包含后端能力，表单与数据展示均为静态实现。
- 不提供多语言版本。

## 9. 本地预览

```bash
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8000/`。

## 10. 目录结构

```
index.html              项目首页，含摘要、章节索引与结果概览
pages/                  19 个页面，项目页与插件演示页并列
assets/css/dossier.css  项目页设计系统
assets/css/style.css    插件演示页样式
assets/js/main.js       导航、目录高亮、标签页、证据筛选与对比滑杆
assets/fonts/           本地字体
assets/img/             SVG 插图
includes/               可选 PHP 片段
```

## 11. 素材许可

- 字体：Noto Sans SC、Instrument Serif、Inter，均采用 SIL Open Font License。
- 插图：SVG 文件，随仓库一并交付。
- 页面中的项目数据与实验结论为示例内容，交付前替换为团队真实材料。
